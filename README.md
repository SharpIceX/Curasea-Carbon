# Curasea Carbon (秋云思-碳)

This project is a personal exploration into **LLM Agents**, serving as a playground to implement some of my long-term thoughts and experimental ideas.

The code is open-sourced under the [Apache-2.0](./LICENSE) license.

## Use

1. Run: `pnpm build` to build the project.
2. Copy the `./data.example` folder to `./data` and fill in your API keys and configurations.
3. Run:`node ./dist/main.ts ./data <command> <options>` to start the CLI interface.
